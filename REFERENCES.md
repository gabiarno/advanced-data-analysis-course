# Instructor technical references

Primary documentation checked while preparing the examples. The repository pins the versions actually executed; latest documentation may describe newer releases. Examples and synthetic data in this repository are original teaching material, not copied official training exercises.

- [scikit-learn cross-validation](https://scikit-learn.org/stable/modules/cross_validation.html): validation strategies and their relation to held-out testing.
- [scikit-learn common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html): preprocessing leakage and pipelines.
- [statsmodels ARIMA](https://www.statsmodels.org/stable/generated/statsmodels.tsa.arima.model.ARIMA.html): model interface and order parameters.
- [SciPy Beta distribution](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.beta.html): density, quantiles and sampling.
- [PySpark 4.0.1 installation](https://spark.apache.org/docs/4.0.1/api/python/getting_started/install.html): Python/Java setup for the Spark lab.
- [scikit-learn neural networks](https://scikit-learn.org/stable/modules/neural_networks_supervised.html): MLP concepts and implementation limits.
- [Goodfellow et al., Generative Adversarial Networks (2014)](https://arxiv.org/abs/1406.2661): adversarial generator/discriminator framework. Our scalar Gaussian toy is a deliberately restricted teaching illustration, not a reproduction of the paper's experiments.

Use these sources to verify API details before changing versions. They do not validate the classroom duration or establish instructor proficiency.
