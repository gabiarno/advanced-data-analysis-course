# Machine learning — proposed session outline

Status: planning outline only. Full notebooks, datasets, slides and assessments for this session are pending. The instructor must rehearse them before delivery.

Audience context: 20 participants in Genoa, English delivery with Arabic interpretation. Use 10 coding pairs and five reporting groups. Technical level is unconfirmed.

Practical goal: Predict delivery time and classify delayed deliveries.

| Minutes | Activity |
|---|---|
| 0–20 | Visual recap and prerequisite check |
| 20–50 | Concept and demonstration for lab A, with interpretation |
| 50–90 | Lab A: Define features/target; fit a regression baseline and model; interpret MAE. |
| 90–105 | Feedback and interpretation |
| 105–120 | Break |
| 120–150 | Concept and demonstration for lab B, with interpretation |
| 150–195 | Lab B: Compare a classifier with a baseline using a confusion matrix; demonstrate a tree and random forest. |
| 195–210 | Break |
| 210–260 | Guided challenge/extensions: Explain overfitting; demonstrate cross-validation and a small hyperparameter search on training data. Introduce clustering and PCA with a visual worked example. |
| 260–285 | Five groups share findings; allow interpretation |
| 285–300 | Exit check and recap |

Scope note: Do not tune on the final test set. Use pipelines for learned preprocessing. Clustering and PCA need scaling considerations; clusters are not automatically meaningful business segments.

This is a provisional practical plan, not a promise that all advanced topics receive equal depth. Keep basic lab tasks short and worked solutions available. If interpretation or prerequisite support takes longer, shorten extensions and agree any contracted scope changes with the organiser. The two breaks are inside the five-hour window; confirm contact-hour requirements.
