# English glossary for interpreter briefing

The interpreter should agree the spoken Arabic equivalents before delivery. Keep code identifiers unchanged. Definitions are intentionally short for live interpretation.

| English term | Plain-English meaning |
|---|---|
| Dataset | A collection of observations |
| Row / observation | One recorded case |
| Column / variable | One recorded property |
| Missing value | Information that is not recorded or available |
| Duplicate | A repeated record; whether it is an error depends on the data |
| Mean | Sum of values divided by their count |
| Median | Middle value after sorting; midpoint of the two middle values for an even count |
| Standard deviation | A measure of spread around the mean |
| Outlier | An unusually distant observation, not necessarily an error |
| Correlation | A measure of association, not proof of causation |
| Feature | An input used by a model |
| Target | The outcome a model is intended to predict |
| Training | Learning model parameters from examples |
| Test set | Held-out examples for final evaluation |
| Baseline | A simple comparison method |
| Regression | Predicting a numerical outcome |
| Classification | Predicting a category |
| Clustering | Grouping observations by similarity without target labels |
| Overfitting | Learning patterns that do not generalise well |
| Data leakage | Using information that should not be available in the modelling process |
| Cross-validation | Repeated training and validation on suitable partitions of training data |
| Hyperparameter | A model setting chosen outside the fitting of model parameters |
| Time series | Observations indexed in time order |
| Seasonality | A repeating pattern linked to a recurring period |
| Prior | A probability distribution before the current evidence is incorporated |
| Likelihood | How compatible observed data are with possible parameter values |
| Posterior | The updated distribution after incorporating evidence |
| MCMC | A family of sampling methods often used to approximate posterior distributions |
| Synthetic data | Artificially generated observations |
| Distributed computing | Processing work across multiple computing resources |
| GAN | A generative model with a generator and a competing discriminator |

Ambiguity reminders: distinguish statistical model from business model, training a model from training people, and a table row from a classroom row. Spell out NLP, MAE and MCMC on first use.
